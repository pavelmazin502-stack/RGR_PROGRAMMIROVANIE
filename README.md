# Расчетно-графическая работа по Программированию

Консольное приложение на C++ для системы Linux, демонстрирующее работу плагинной архитектуры динамических библиотек (`.so`) на примере криптографических алгоритмов шифрования текста и файлов.

## 📝 Описание
Приложение представляет собой модульную систему, где каждый криптографический алгоритм собран как отдельная динамическая библиотека (плагин) и подгружается на лету во время выполнения программы с помощью системных вызовов `dlopen` и `dlsym`.

В проекте реализованы следующие алгоритмы:
* **Литорея (бесключевой)** — древнерусский шифр взаимной замены согласных букв.
* **Атбаш** — моноалфавитный шифр подстановки, зеркально заменяющий буквы алфавита.
* **Шифр Виженера** — полиалфавитный шифр подстановки, использующий ключевое слово.
* **Шифр Скитала** — классический шифр перестановки, основанный на геометрии цилиндра.
* **RC4** — потоковый шифр, основанный на генерации псевдослучайной последовательности байт.
* **RSA** — асимметричный алгоритм шифрования, основанный на математической сложности факторизации больших чисел.

## ✨ Возможности
* **Модульная архитектура:** Автоматическое обнаружение и загрузка алгоритмов из папки `plugins`.
* **Интуитивно понятный интерфейс:** Разделение операций для работы с текстом и файлами.
* **Операции с текстом:** Ввод строки с клавиатуры, интерактивный выбор алгоритма шифрования/дешифрования и вывод результата в консоль.
* **Операции с файлами:** Чтение данных любого формата (включая бинарные данные), применение шифра и сохранение результата в новый файл через встроенный менеджер файлов.

## 🛠️ Стек технологий
* **Язык программирования:** C++ (с поддержкой стандартов ISO C++17 для Unicode-строк).
* **Связывание модулей:** Динамические библиотеки Linux (`.so` файлы).
* **Операционная система:** Linux (тестировалось на семействе дистрибутивов Mint/Ubuntu).

## 🚀 Сборка и запуск проекта

Все операции выполняются вручную через терминал в корневой папке проекта.

### 1. Подготовка окружения
Перед компиляцией убедитесь, что в корне проекта существует папка для плагинов:
```bash
mkdir -p plugins
```

### 2. Компиляция динамических библиотек (плагинов)

```bash
g++ -fPIC -shared -o plugins/libLitorei.so Litorei.cpp
g++ -std=c++17 -fPIC -shared -o plugins/libatbash.so atbash.cpp
g++ -fPIC -shared -o plugins/libvigenere.so vigenere.cpp
g++ -fPIC -shared -o plugins/libSkitala.so Skitala.cpp
g++ -fPIC -shared -o plugins/librc4.so rc4_algorithm.cpp
g++ -fPIC -shared -o plugins/librsa.so rsa_algorithm.cpp
```

### 3. Компиляция основного приложения
Компиляция ядра программы (`main.cpp`) совместно с модулем файлового менеджера (`file_manager.cpp`). Флаг `-Wl,-rpath` зашивает относительный путь к папке с плагинами, избавляя от необходимости настраивать системную переменную `LD_LIBRARY_PATH`:

```bash
g++ main.cpp file_manager.cpp -o main -L./plugins -Wl,-rpath=./plugins
```

### 4. Запуск программы
```bash
./main
```
